# Examples for MicroSculpt AI 2.0

This folder contains example code files to test the multi-language capabilities of MicroSculpt AI.

## Available Examples

### 1. `example_ecommerce.py` (Python)
E-commerce application with:
- User authentication
- Shopping cart management
- Payment processing
- Inventory management

**Expected Output**: ~4 microservices (Auth, Cart, Payment, Inventory)

### 2. `example_blog.js` (JavaScript)
Blog platform with:
- User registration
- Authentication
- Post creation
- Follower notifications

**Expected Output**: ~3 microservices (User, Post, Notification)

## How to Use

1. Run MicroSculpt AI:
   ```bash
   streamlit run app.py
   ```

2. Upload any example file in Module 1

3. Follow the 6-module workflow to see the AI in action!

## Testing Tips

- Try uploading the Python example first to see the full workflow
- Then try the JavaScript example to test multi-language support
- Compare how the AI groups functions differently based on language patterns
